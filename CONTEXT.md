# Markdown publications

This domain describes project-authored Markdown and the branded Markdown
publications generated around it.

## Language

**Project corpus**:
The project-authored explanations, examples, and supporting material enclosed
by the surrounding brand framing.

**Source document**:
The Markdown document edited by project authors, from which the reader-facing
publication is produced.

**Markdown publication**:
A reader-facing Markdown document containing project content and any selected
brand framing. A repository README is the initial publication type.

**Markdown theme**:
A reusable expression of an identity through Markdown framing around a corpus.
_Avoid_: Stylesheet, which suggests control over the host's visual renderer.

**Markdown frame**:
The opening and closing material contributed by a Markdown theme. Either part
may intentionally be empty.

**Theme stack**:
The explicitly ordered collection of Markdown themes surrounding a corpus,
from the outermost identity to the innermost one.

**Generated README**:
The repository entry document produced from its source corpus and selected
Markdown frames, committed for visitors to read.
